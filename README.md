# CV Романа Путилова

Единый статический CV для GitHub Pages: адаптивная web-версия и один PDF для отправки, ATS-разбора и печати на A4. Сборка, JavaScript, CDN и внешние шрифты не нужны.

## Что внутри

- `index.html` — единственный источник содержания и web-версия CV.
- `Roman-Putilov-CV.pdf` — единый четырёхстраничный CV формата A4.
- `styles.css` — экранная типографика, адаптивность и внутренние переходы.
- `print.css` — отдельная A4-компоновка того же документа.
- `assets/` — портрет, favicon и самохостящийся Geologica Variable с лицензией OFL-1.1.
- `robots.txt` и `sitemap.xml` — индексация GitHub Pages.

## Как опубликовать

1. Откройте репозиторий `PutilovR/CV` на GitHub.
2. Замените прежние публичные файлы в корне репозитория **содержимым** этой папки: старые альтернативные HTML и PDF в репозитории оставаться не должны.
3. Сделайте один commit с новой единой версией.
4. В **Settings → Pages** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`.
5. После публикации откройте `https://putilovr.github.io/CV/`, проверьте кнопку «Скачать CV» и прямую ссылку `https://putilovr.github.io/CV/Roman-Putilov-CV.pdf`.

GitHub Pages обычно обновляет страницу за несколько минут. Имена файлов чувствительны к регистру.

## Как обновлять PDF

После изменения текста откройте опубликованный или локальный `index.html` в актуальном Chrome/Edge и выберите **Печать → Сохранить как PDF**:

- формат: A4;
- масштаб: 100%;
- колонтитулы браузера: выключены;
- фоновые изображения: включены.

Сохраните файл под неизменным именем `Roman-Putilov-CV.pdf` и загрузите его вместе с обновлённым HTML.

## Проверено

- desktop, tablet и mobile без горизонтальной прокрутки;
- один `h1`, уникальные `id`, рабочие внутренние якоря и заметный keyboard focus;
- один видимый CTA «Скачать CV» и один PDF в публичной папке;
- четыре A4-страницы без пустых страниц и разрывов должностей;
- весь опыт на одной странице PDF;
- извлекаемый текст в последовательном порядке, `/Lang ru`, тегированная структура и активные контакты;
- один шрифт и ровно четыре типографических масштаба на экране и в печати.
